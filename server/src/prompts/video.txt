### 2. ChalkText (粉笔字)

```tsx
const ChalkText: React.FC<{
  text: string;
  fontSize?: number;
  color?: string;
  delay?: number;
  frame?: number;
}> = ({ text, fontSize = 48, color = "#FFFFFF", delay = 0, frame = 0 }) => {
  const opacity = interpolate(frame, [delay, delay + 20], [0, 1]);
  return (
    <div style={{
      opacity,
      fontSize,
      color,
      fontFamily: "Georgia, serif",
      textShadow: "2px 2px 4px rgba(0,0,0,0.3)",
    }}>
      {text}
    </div>
  );
};
```

## 题目类型适配指南

### 题型1：称重/液体问题

**特点**：已知不同数量下的总重量，求单位重量

**示例**：
- 量杯装水问题（本题）
- 瓶子装油问题
- 水果重量问题

**分镜建议**：
1. 开场：展示空容器和量杯/单位
2. 已知条件：展示两次称重结果
3. 分析：容器对比图
4. 计算：差量 ÷ 差杯数
5. 答案：单位重量 + 验算

### 题型2：行程问题

**特点**：速度、时间、路程的关系

**分镜建议**：
1. 开场：展示题目
2. 已知条件：提取速度/时间/路程
3. 分析：线段图/示意图
4. 计算：公式推导
5. 答案：最终结果 + 验算

### 题型3：图形/几何问题

**特点**：面积、周长、体积计算

**分镜建议**：
1. 开场：展示图形
2. 已知条件：标注尺寸
3. 分析：切割/拼接示意图
4. 计算：公式应用
5. 答案：结果 + 单位

### 题型4：应用题

**特点**：综合运用多个知识点

**分镜建议**：
1. 开场：情境描述
2. 已知条件：关键信息提取
3. 分析：问题拆解
4. 计算：分步解答
5. 答案：最终结果

## 动画效果模板

### 淡入效果（文字/图片出现）
```tsx
const opacity = interpolate(frame, [delay, delay + 20], [0, 1]);
```

### 水位/进度动画
```tsx
const progress = spring({
  frame: frame - startFrame,
  fps: 30,
  config: { damping: 15 },
});
const height = interpolate(progress, [0, 1], [0, maxHeight]);
```

### 弹跳效果（答案揭示）
```tsx
const scale = spring({
  frame: frame - startFrame,
  fps: 30,
  config: { damping: 10 },
});
const transform = `scale(${scale})`;
```
