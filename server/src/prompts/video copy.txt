## 整体风格

### 背景设计
- **黑板教学风格**：绿色黑板背景 + 木质边框
- **适用场景**：数学、物理等理科题目讲解

### 配色方案

```
黑板背景：  #2D5A3D (深绿色)
木质边框：  #8B4513 (棕色)
粉笔白字：  #FFFFFF
粉笔黄字：  #FCD34D
强调色：    #10B981 (箭头等)
```

## 组件库

### 1. Blackboard (黑板背景)

```tsx
const Blackboard: React.FC<{ children: React.ReactNode }> = ({ children }) => {
  return (
    <div style={{
      backgroundColor: "#2D5A3D",
      border: "20px solid #8B4513",
      borderRadius: 10,
    }}>
      {/* 纹理效果 */}
      <div style={{
        background: "repeating-linear-gradient(...)"
      }} />
      {children}
    </div>
  );
};
```

### 2. ChalkText (粉笔字)

```tsx
const ChalkText: React.FC<{
  text: string;
  fontSize?: number;
  color?: string;
  delay?: number;
  frame?: number;
}> = ({ text, fontSize = 48, color = "#FFFFFF", delay = 0, frame = 0 }) => {
  const opacity = interpolate(frame, [delay, delay + 20], [0, 1]);
  return (
    <div style={{
      opacity,
      fontSize,
      color,
      fontFamily: "Georgia, serif",
      textShadow: "2px 2px 4px rgba(0,0,0,0.3)",
    }}>
      {text}
    </div>
  );
};
```

## 动画效果模板

### 淡入效果（文字/图片出现）
```tsx
const opacity = interpolate(frame, [delay, delay + 20], [0, 1]);
```

### 水位/进度动画
```tsx
const progress = spring({
  frame: frame - startFrame,
  fps: 30,
  config: { damping: 15 },
});
const height = interpolate(progress, [0, 1], [0, maxHeight]);
```

### 弹跳效果（答案揭示）
```tsx
const scale = spring({
  frame: frame - startFrame,
  fps: 30,
  config: { damping: 10 },
});
const transform = `scale(${scale})`;
```

# 示例代码

import {
  AbsoluteFill,
  interpolate,
  Sequence,
  spring,
  useCurrentFrame,
  useVideoConfig,
  Html5Audio,
} from "remotion";

const Step1: React.FC = () => {
  const frame = useCurrentFrame();
  const { fps } = useVideoConfig();

  const titleOpacity = spring({ fps, frame, config: { damping: 15 } });
  const peopleOpacity = spring({ fps, frame: frame - 20, config: { damping: 15 } });

  return (
    <AbsoluteFill style={{ backgroundColor: COLORS.background }}>
      {/* Title */}
      <div
        style={{
          position: "absolute",
          top: 120,
          left: 0,
          right: 0,
          textAlign: "center",
          opacity: titleOpacity,
          transform: `translateY(${(1 - titleOpacity) * 30}px)`,
        }}
      >
        <div
          style={{
            fontFamily: FONT_FAMILY,
            fontSize: 42,
            fontWeight: "bold",
            color: COLORS.text,
            lineHeight: 1.6,
          }}
        >
          三年级有198人，每条船最多坐8人，
          <br />
          所有同学一起划船，至少需要多少条船？
        </div>
      </div>

      {/* Visual representation */}
      <div
        style={{
          position: "absolute",
          bottom: 100,
          left: 0,
          right: 0,
          display: "flex",
          justifyContent: "center",
          gap: 40,
          opacity: peopleOpacity,
        }}
      >
        {/* 198 students representation */}
        <div style={{ textAlign: "center" }}>
          <div
            style={{
              fontFamily: FONT_FAMILY,
              fontSize: 24,
              color: COLORS.text,
              marginBottom: 20,
            }}
          >
            198名同学
          </div>
          <div
            style={{
              display: "flex",
              flexWrap: "wrap",
              width: 300,
              justifyContent: "center",
              gap: 4,
            }}
          >
            {Array.from({ length: 24 }).map((_, i) => (
              <div key={i} style={{ display: "flex", gap: 2, marginBottom: 2 }}>
                {Array.from({ length: 8 }).map((_, j) => (
                  <Person
                    key={i * 8 + j}
                    x={0}
                    y={0}
                    color={j < 4 ? COLORS.person : COLORS.personAlt}
                    scale={0.6}
                  />
                ))}
              </div>
            ))}
            {Array.from({ length: 6 }).map((_, i) => (
              <Person key={192 + i} x={0} y={0} color={COLORS.person} scale={0.6} />
            ))}
          </div>
        </div>

        {/* Arrow */}
        <div
          style={{
            display: "flex",
            alignItems: "center",
            fontSize: 40,
            color: COLORS.primary,
          }}
        >
          →
        </div>

        {/* Boat representation */}
        <div style={{ textAlign: "center" }}>
          <div
            style={{
              fontFamily: FONT_FAMILY,
              fontSize: 24,
              color: COLORS.text,
              marginBottom: 20,
            }}
          >
            每船8人
          </div>
          <Boat x={0} y={0} scale={1.5} />
          <div
            style={{
              display: "flex",
              justifyContent: "center",
              gap: 4,
              marginTop: 10,
            }}
          >
            {Array.from({ length: 8 }).map((_, i) => (
              <Person
                key={i}
                x={0}
                y={0}
                color={i < 4 ? COLORS.person : COLORS.personAlt}
                scale={0.7}
              />
            ))}
          </div>
        </div>
      </div>
    </AbsoluteFill>
  );
};

export default Step1;
